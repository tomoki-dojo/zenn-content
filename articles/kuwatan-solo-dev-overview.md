英語を声に出して練習すると、クワガタが育つ。そんな英語学習ゲーム「**喋って！育てろ！英クワたん**」を、1人で作ってリリースしました。

https://app.upskillenglish.bear-fruit.online/welcome?utm_source=zenn&utm_medium=article&utm_campaign=kuwatan-solo-dev-overview

開発はほぼ独学で、仕事の合間に作りました。この記事では、作ったものの全体像を、

- どういう仕組みで「話す練習」をさせているか
- AIの判定に実際いくらかかっているか
- 課金と広告をどう設計したか

の3つを中心に、実際の数字つきでまとめます。細かい実装は、別の記事で1つずつ書いていく予定です。

## なぜ作ったか

英語学習アプリはたくさんありますが、多くは「読めた」「正しい選択肢を選べた」で終わります。でも、話せるようになりたい人に必要なのは、**口から英語が出ること**です。

そこでこのアプリでは、全部のステップで「実際に声に出す」ことを前提にしました。画面をタップして正解を選ぶだけの問題は、作っている途中でいくつも作り直しています。

もう1つの問題は、続かないことです。声に出す練習は地味で、1人だと3日で終わります。そこで、**練習した量だけクワガタ（や虫たち）が育つ**ゲームを組み合わせました。夏休みの虫捕りや飼育の楽しさは、説明しなくても伝わるからです。

## 全体の構成

| 役割 | 使っているもの |
|---|---|
| フロント・API | Next.js 15（App Router） |
| DB・認証 | Supabase（Postgres、マジックリンクでログイン） |
| 課金 | Stripe（Checkout ＋ カスタマーポータル ＋ Webhook） |
| AI判定 | Gemini 3.5 Flash-Lite（予備に Claude Haiku 4.5） |
| 音声入力 | ブラウザの Web Speech API |
| サーバー | ConoHa VPS（Docker ＋ Caddy） |
| 計測・広告 | GA4、AdSense |

最初は Vercel の無料プランで動かしていましたが、Stripe で課金を付けた時点で「商用利用」にあたると気づき、VPS に移しました。今は同じ VPS で、自動化ツールの n8n や別の自作アプリも一緒に動いています。

## 「話す練習」の仕組み：Stage0〜5

練習は、Stage1〜5の一本道です（Stage0は基礎知識のクイズで、一本道の外にあります）。

| Stage | 中身 | 判定 |
|---|---|---|
| 1 | 音読・シャドーイング | 自己申告（AIなし） |
| 2 | 瞬間英作文（声に出して組み立てる） | 自己申告（AIなし） |
| 3 | 型を崩して、自分の言葉で言い換える | **AIが意味を判定** |
| 4 | AIとロールプレイ（5往復の会話） | **AIが会話全体を判定** |
| 5 | 応用（日常・ビジネスの難しめの場面） | **AIが会話全体を判定** |

ポイントは、**AIを使うのは Stage3〜5 だけ**にしたことです。

Stage1・2は「同じ表現を何度も口に出して覚える」量の練習なので、正誤をAIに判定させる必要がありません。答えを確認して「言えた／言えなかった」を自分で押してもらう形にしています。ここでAIを使わないことが、あとで説明するコストに大きく効いています。

同じ表現を連続で何回か言えたら「卒業」で、卒業した数で次のStageが開きます。

## AIの判定にいくらかかっているか

Stage4（AIとの5往復の会話）を実際に3回やって、APIの使用量を測りました。

| | 1回の会話あたり |
|---|---|
| リクエスト数 | 15 |
| 入力トークン | 約16.9K |
| 出力トークン | 約1.6K |
| 費用 | 約$0.009（**約0.45円**） |

Stage5もほぼ同じで、約0.4円でした。

※単価は $0.30（入力）／$2.50（出力）per 1M トークン、1ドル150円で計算しています。単価は公式の料金ページではなく第三者の情報で確認したものなので、目安として見てください。

### コストを抑えるためにやったこと

**1. 速くて安いモデルを主にして、落ちたときだけ別のAIに切り替える**

判定は Gemini 3.5 Flash-Lite を主にしています。実測で応答の中央値は約1秒でした。混雑やエラーのときは短いタイムアウトで見切りをつけて、Claude Haiku 4.5（中央値約1.8秒）に切り替えます。どちらかが落ちても、待ち時間が延びすぎないようにしています。

**2. 「答えが1つに決まるもの」は、AIに1回だけ作らせて保存する**

たとえば Stage3 のヒント（お手本の一部を空欄にした文）は、表現ごとに決まるものです。最初に誰かが開いたときだけAIに作らせてDBに保存し、2人目からは保存したものを返します。ユーザーが増えても、コストはほぼ増えません。

**3. お手本と完全に一致したら、AIを呼ばない**

Stage3で、お手本とまったく同じ文を言えた場合は、AIに聞くまでもなく正解です。この場合は判定を省略しています。

## 続けたくなる仕組み：クワガタ育成

![](/images/kuwatan-solo-dev-overview/map.png)

練習とゲームは、こうつながっています。

- 表現を**10個習得するごとに「採集チャンス」が1回**たまる
- チャンスを使って、エリアを選んで採集に出かける
- 出かける前に「10秒単語チャレンジ」があり、正解数が多いほどレアが出やすくなる
- 捕まえた虫は棚の水槽で歩き回り、日数で卵→幼虫→蛹→成虫と育つ
- Stageの節目では、主役のクワガタ「クワたんシリーズ」が卵で届く

「英語を聞かせると育つ不思議なクワガタ」という設定にしているので、練習した量と育つことが、ちゃんと意味でつながるようにしています。

### 有料ガチャにはしない

採集にはレア度（コモン／レア／激レア）がありますが、**お金を払って抽選を回す仕組みは作っていません**。採集チャンスは練習でしか増えませんし、Proにしてもレアの出やすさは変わりません。

抽選に課金させると一気に売上が立ちそうに見えますが、英語学習アプリでそれをやると「勉強させたいのか、ガチャを回させたいのか」が分からなくなります。法律面（景品表示法など）の論点も出てくるので、最初から外しました。

## 課金の設計

課金は **Pro（月680円・年6,800円）の1本**だけです（2026年12月31日までは先行者価格で月480円。後述）。英クワたんとは別に、表現や単語を調べられる本体アプリ（UpskillEnglish）もあり、Proにすると両方がProになります。

| | Free | Pro |
|---|---|---|
| AI判定（Stage3） | 1日8回 | 1日50回 |
| AI会話（Stage4・5） | 1日2回（はじめの7日間は3回） | 1日10回 |
| 棚に飾れる虫の種類 | 10種類まで | 無制限 |
| 採集チャンスのたまり方 | ふつう | 2倍 |
| Pro限定のエリア・虫 | なし | あり |
| 広告 | あり | なし |

### カード登録なしで7日間試せる、先行者は月480円

リリースに合わせて、2つ用意しました。

- **7日間の無料お試し（カード登録なし）**：お試しが終わると、自動でFreeに戻ります。カードを登録しない限り、お金はかかりません
- **先行者価格**：2026年12月31日までにProを始めた人は、**月480円**（月払いのみ）。そのあとも480円のまま続けられます

「無料お試し」は、カードを先に登録させる形が多いと思います。そのほうが課金に切り替わる人は増えますが、「解約し忘れて払っていた」は英語学習アプリで一番やってはいけない体験だと思ったので、カードなしにしました。

Stripe Checkout だと、設定3つで作れます。

```ts
const session = await stripe.checkout.sessions.create({
  mode: "subscription",
  line_items: [{ price: priceId, quantity: 1 }],
  // カードがなくても申し込めるようにする
  payment_method_collection: "if_required",
  subscription_data: {
    trial_period_days: 7,
    trial_settings: {
      // お試し終了時にカードがなければ、請求せずに解約
      end_behavior: { missing_payment_method: "cancel" },
    },
  },
  // 申し込みボタンの下に注意書きを出す
  custom_text: {
    submit: {
      message: "7日間のお試しが終わると、自動的にFreeプランに戻ります。カードを登録しない限り、お支払いが発生することはありません。",
    },
  },
  // ...success_url など
});
```

お試しは1人1回です。過去にサブスクリプションを持ったことがあるかを Stripe に問い合わせて、2回目以降は通常の申し込みにしています。

その代わり、お試し中は部屋の上に「あと◯日」を出し、最終日の前日と当日は「明日で／今日でお試しが終わります。カードを登録すると月480円のまま続けられます」に切り替えています。黙って終わるより、続けたい人がちゃんと気づける形にしました。

### 回数はコストより「体験」で決めた

0.45円の会話を1日10回使い切っても、1日4.5円、Stage4・5の両方で月270円ほどです。月680円に対して赤字にはなりません。

Freeの回数は、コストより「卒業のしやすさ」で決めました。Stage4は同じ場面で3回続けて合格すると卒業なので、1日2回だと初日に1つも卒業できません。そこで、**はじめての7日間だけ1日3回**にしています。登録した日からではなく、そのStageを初めて遊んだ日から数えるので、Stage4にたどり着いた人は必ずこの7日間を使えます。

### 無料の回数は「減らさない、足すだけ」

リリース前に、あえて控えめな数字で決めました。リリース後に無料の回数を減らすと「改悪」になりますが、増やすのは「うれしいお知らせ」にできるからです。今後の調整は、増やす方向だけにするつもりです。

### 一番課金したくなるのは「棚がいっぱい」のとき

遊んでいて一番「Proにしようかな」と思う瞬間は、AIの回数よりも、**棚に飾れる種類が10種類で埋まったとき**だと考えています。もう捕まえた子が、棚に飾れないからです。

なので、11種類目を捕まえた結果画面で「棚がいっぱいで、この子は飾れない…」と出して、Proの案内につなげています。棚には、隠れている種類の数だけ鍵付きの水槽を並べています。

## 広告：タイマーでは出さない

Freeの人には AdSense の広告を出しています。ただ、**一定時間ごとに勝手に出す、ということはしていません**。

AdSense は、ユーザーの操作なしに広告を出したり再読み込みしたりするのを認めていません。それに、声に出して練習している最中に広告が割り込んだら、一番やめたくなる瞬間になります。

そこで、

- 練習から部屋・棚・図鑑に戻ったとき
- 採集の結果を閉じたとき

という**区切りのいい場面で、前回の広告から5分以上たっていたら**、ページの上に広告を1つ出すだけにしています。

正直に書くと、リリースしたばかりで、ユーザーはまだほとんどいません。課金の仕組みは整えたので、ここからは「来てくれた人が、どこで止まって、どこで課金するか」を見ていく段階です。

そのために、GA4 で次のイベントを取っています。

- Proの案内ページを見た／決済に進んだ／課金した（どの導線から来たか付き）
- 棚の上限に当たった
- AIの回数の上限に当たった

数字がたまったら、また記事にします。
