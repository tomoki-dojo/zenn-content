英語を声に出して練習すると、クワガタが育つ。そんな英語学習ゲーム「**喋って！育てろ！英クワたん**」を、1人で作ってリリースしました。

https://app.upskillenglish.bear-fruit.online/welcome?utm_source=zenn&utm_medium=article&utm_campaign=kuwatan-solo-dev-overview

開発はほぼ独学で、仕事の合間にコツコツ作ってきました。この記事では、作ったものの全体像を、

- 「話す練習」をどういう仕組みにしたか
- AIの判定に実際いくらかかっているか
- 課金と広告をどう設計したか

の3つを中心に、実際の数字つきでまとめています。細かい実装は、別の記事で1つずつ書いていく予定です。

## なぜ作ったか

英語って、スキルなんですよね。読めるようになっても、口から出す練習をしないと話せるようにはならない。でも、その「練習する方法」がなかなか無いのが現状だと思っています。

音読やシャドーイングで練習しようと思っても、ちょうどいいネタが無いんですよねぇ…。英語のニュースは専門的な言葉が多いし、ネイティブのポッドキャストは速くて意味が分からない。AI相手に英会話、というのも流行っていますが、いざマイクをオンにしても何を喋っていいのやら。AIに「今日はいい天気ですね」と言ってもねぇ、という話です。

じゃあ、練習用のコンテンツを作ってしまえばいい。今はAIの力を借りられるので、まずは「喋る前提になるシチュエーション」を作るところから始めました。

そこから段階を追って声に出す練習ができるようにして、「せっかくなら面白くしたい、ゲーム要素を付けたら続くんじゃない？」と思って、育成ゲームを組み合わせています。

ちなみに最初は箱庭ゲームにするつもりで、建物も何棟か描いていました。でも「建ててしまえばおしまいだし、見た目が変わっても『ふーん』くらいだな…」と思ってしまって、泣く泣く全部ボツに。育つし種類も多いし、大人の趣味としての飼育もあるし、ということで虫の育成ゲームに落ち着きました。虫の絵も自分で描いているので、そこから虫を描きまくりました笑

## 全体の構成

| 役割 | 使っているもの |
|---|---|
| フロント・API | Next.js 15（App Router） |
| DB・認証 | Supabase（Postgres、マジックリンクでログイン） |
| 課金 | Stripe（Checkout ＋ カスタマーポータル ＋ Webhook） |
| AI判定 | Gemini 3.5 Flash-Lite（予備に Claude Haiku 4.5） |
| 音声入力 | ブラウザの Web Speech API |

最初は Vercel の無料プランで動かしていたんですが、Stripe で課金を付けた時点で「商用利用」にあたると気づいて、VPS に移しました。今は同じ VPS で、自動化ツールの n8n や別の自作アプリも一緒に動いています。

## 「話す練習」の仕組み：Stage1〜5

練習は Stage1〜5 の一本道で、少しずつ「自分の言葉で話す」に近づいていきます（Stage0 は基礎知識のクイズで、一本道の外にあります）。

| Stage | 中身 | 判定 |
|---|---|---|
| 1 | 音読・シャドーイング | 自己申告（AIなし） |
| 2 | 瞬間英作文 | 自己申告（AIなし） |
| 3 | 型を崩して、自分の言葉で言い換える | **AIが意味を判定** |
| 4 | AIとロールプレイ（日常の場面で5往復の会話） | **AIが会話全体を判定** |
| 5 | 応用（仕事など、少し難しめの場面で会話） | **AIが会話全体を判定** |

AIを使うのは Stage3〜5 だけにしています。

Stage1・2 は、同じ表現を何度も口に出して覚える「量」の練習です。正誤をAIに判定させる必要はないので、答えを確認して、言えたかどうかを自分で判断してもらう形にしました。ここでAIを使っていないのが、あとで書くコストにかなり効いています。

Stage4・5 の判定は、一言一句の正しさではなく「その場面で話が通じたかどうか」です。少しぎこちなくても伝わっていれば合格で、不自然だったところは、言い直しの例を出すようにしています。

## AIの判定にいくらかかっているか

Stage4（AIとの5往復の会話）を実際に3回やって、APIの使用量を測りました。

| | 1回の会話あたり |
|---|---|
| リクエスト数 | 15 |
| 入力トークン | 約16.9K |
| 出力トークン | 約1.6K |
| 費用 | 約$0.009（**約0.45円**） |

Stage5 もほぼ同じで、約0.4円でした。

※単価は $0.30（入力）／$2.50（出力）per 1M トークン、1ドル150円で計算しています。単価は公式の料金ページではなく第三者の情報で確認したものなので、目安として見てください。

### コストを抑えるためにやったこと

**1. 速くて安いモデルを主にして、落ちたときだけ別のAIに切り替える**

判定は Gemini 3.5 Flash-Lite を主にしています。実測で応答の中央値は約1秒でした。混雑やエラーのときは短いタイムアウトで見切りをつけて、Claude Haiku 4.5（中央値約1.8秒）に切り替えます。どちらかが落ちても、待ち時間が延びすぎないようにしています。

**2. 「答えが1つに決まるもの」は、AIに1回だけ作らせて保存する**

たとえば Stage3 のヒント（お手本の一部を空欄にした文）は、表現ごとに決まるものです。最初に誰かが開いたときだけAIに作らせてDBに保存して、2人目からは保存したものを返しています。ユーザーが増えても、ここのコストはほぼ増えません。

**3. お手本と完全に一致したら、AIを呼ばない**

Stage3 で、お手本とまったく同じ文を言えた場合は、AIに聞くまでもなく正解です。この場合は判定を省略しています。

## 練習とゲームのつながり

![](/images/kuwatan-solo-dev-overview/map.png)

練習とゲームは、こうつながっています。

- 英語の表現を**10個覚えるごとに「採集チャンス」が1回**たまる
- チャンスを使って、エリアを選んで虫の採集に出かける
- 採集の前に、時間内に英単語の意味を答えるミニゲームがあって、成績がいいほどレアや激レアが出やすくなる
- 捕まえた虫（成虫）は棚の水槽で飼えて、名前も付けられる。水槽の中を歩き回って、ちょっと面白いアクションをする虫もいます
- Stage の節目では、主役のクワガタ「クワたんシリーズ」がタマゴで届いて、タマゴ→幼虫→蛹→成虫と育っていく。日数に加えて、練習するほど早く育つ

採集で手に入るのは成虫だけで、タマゴから育てられるのは今のところクワたんシリーズだけです。ほかの虫もタマゴから育てられるようにするかは、今後のバージョンアップ次第かなと思っています。虫の種類もこれから増やしていく予定なんですが、描けば描くほど増やせるのが魅力でもあり、恐ろしいところでもあり…笑

## 課金の設計

課金は **Pro（月680円・年6,800円）の1本**です（2026年12月31日までは先行者価格で月480円。後で書きます）。英クワたんとは別に、表現や単語を調べられる本体アプリ（UpskillEnglish）もあって、Proにすると両方がProになります。

| | Free | Pro |
|---|---|---|
| AI判定（Stage3） | 1日8回 | 1日50回 |
| AI会話（Stage4・5） | 1日2回（はじめの7日間は3回） | 1日10回 |
| 棚に飾れる虫の種類 | 10種類まで | 無制限 |
| 採集チャンスのたまり方 | ふつう | 2倍 |
| Pro限定のエリア・虫 | なし | あり |
| 広告 | あり | なし |

ProとFreeの差をどう付けるかは、正直かなり悩んだところです。Freeでも練習とゲームの楽しさは伝わるようにしつつ、Proでは「これだけできるならお金を払ってでもやりたいなぁ」と思ってもらえるようにしたかったので、練習の回数だけでなく、ゲーム側の楽しみ（エリア、虫、育つ速さ）にも差を付けています。

### 回数はコストより「体験」で決めた

0.45円の会話を1日10回使い切っても1日4.5円で、Stage4・5の両方を毎日使い切っても月270円ほどです。月680円に対して赤字にはなりません。

なのでFreeの回数は、コストより「卒業のしやすさ」で決めました。Stage4 は同じ場面で3回続けて合格すると卒業なので、1日2回だと初日に1つも卒業できないんですよね。そこで、**はじめの7日間だけ1日3回**にしています。登録した日からではなく、そのStageを初めて遊んだ日から数えるので、Stage4 にたどり着いた人は必ずこの7日間を使えます。

### 無料の回数は「減らさない、足すだけ」

Freeの回数は、リリース前にあえて控えめに決めました。リリース後に無料の回数を減らすと「改悪」になって感じが悪いですが、増やすのは「うれしいお知らせ」にできるからです。今後の調整は、増やす方向でやっていくつもりです。

### 一番「Proにしようかな」と思うのは、棚がいっぱいのとき

遊んでいて一番「Proにしようかな」と思う瞬間は、AIの回数よりも、**棚に飾れる種類が10種類で埋まったとき**だと考えています。せっかく捕まえた子が、棚に飾れないからです。

なので、11種類目を捕まえた結果画面で「棚がいっぱいで、この子は飾れない…」と出して、Proの案内につなげています。棚には、隠れている種類の数だけ鍵付きの水槽を並べています。

### カード登録なしで7日間試せる、先行者は月480円

リリースに合わせて、2つ用意しました。

- **7日間の無料お試し（カード登録なし）**：お試しが終わると、自動でFreeに戻ります
- **先行者価格**：2026年12月31日までにProを始めた人は、**月480円**（月払いのみ）。そのあともずっと480円のままです

Stripe Checkout だと、設定3つでカードなしのお試しが作れます。

```ts
const session = await stripe.checkout.sessions.create({
  mode: "subscription",
  line_items: [{ price: priceId, quantity: 1 }],
  // カードがなくても申し込めるようにする
  payment_method_collection: "if_required",
  subscription_data: {
    trial_period_days: 7,
    trial_settings: {
      // お試し終了時にカードがなければ、請求せずに解約
      end_behavior: { missing_payment_method: "cancel" },
    },
  },
  // 申し込みボタンの下に注意書きを出す
  custom_text: {
    submit: {
      message: "7日間のお試しが終わると、自動的にFreeプランに戻ります。カードを登録しない限り、お支払いが発生することはありません。",
    },
  },
  // ...success_url など
});
```

お試しは1人1回です。過去にサブスクリプションを持ったことがあるかを Stripe に問い合わせて、2回目以降は通常の申し込みにしています。

お試し中は部屋の上に「あと◯日」を出して、最終日の前日と当日は「明日で／今日でお試しが終わります。カードを登録すると月480円のまま続けられます」に切り替わるようにしました。続けたい人が、終わる前に気づけるようにしています。

## 広告：タイマーでは出さない

Freeの人には AdSense の広告を出しています。最初は「滞在時間が長いアプリだから、5分ごとに出せばいいかな」と思っていたんですが、AdSense はユーザーの操作なしに広告を出したり再読み込みしたりするのを認めていません。それに、声に出して練習している最中に広告が割り込んできたら、自分でもやめたくなるなぁ、と。

そこで、

- 練習から部屋・棚・図鑑に戻ったとき
- 採集の結果を閉じたとき

という**区切りのいい場面で、前回の広告から5分以上たっていたら**、ページの上に広告を1つ出す形にしています。

正直に書くと、リリースしたばかりで、ユーザーはまだほとんどいません。課金の仕組みは整えたので、ここからは「来てくれた人が、どこで止まって、どこでProにするか」を見ていく段階です。

そのために、GA4 で次のイベントを取っています。

- Proの案内ページを見た／決済に進んだ／課金した（どの導線から来たか付き）
- 棚の上限に当たった
- AIの回数の上限に当たった

数字がたまったら、また記事にするつもりです。

## おわりに

1人で作ると、設計の判断を全部自分で決められる代わりに、全部自分で考えないといけません。AIの判定をどこで使ってどこで使わないか、Freeでどこまで遊べてProで何が増えるか、広告をどこで出すか…このあたりは、どれも「練習する人が気持ちよく続けられるか」を軸に、かなり時間をかけて決めてきました。

英語の「話す練習」は、結局のところ量だと思っています。その量を、虫を集めて育てる楽しさで少しでも後押しできたら、というのがこのアプリに込めたいちばんの思いです。この記事が、個人で何か作って課金まで付けたい人の参考になればうれしいですし、英語を声に出す練習を続けたい人には、クワガタを育てるついでに英語を口に出してもらえたらうれしいです🪲
