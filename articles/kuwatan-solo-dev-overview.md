## なぜ作ったか

- ゴールは「読める・選べる」ではなく「口から英語が出る」こと
- 続けるために、クワガタ育成のゲームを組み合わせた

## 全体の構成

- Next.js 15 ＋ Supabase ＋ Stripe
- ConoHa VPS（Docker ＋ Caddy）
- AI判定は Gemini（予備に Claude）
- 音声入力は Web Speech API

## AIの判定

- Stage1〜5の設計。AIが判定するのは Stage3〜5 だけ
- 1回の会話（5往復）が約0.45円
- ヒントはAIで1回だけ作ってキャッシュ。2人目以降はほぼ0円

## 続けたくなる仕組み

- 習得した表現10件で採集チャンス1回、棚・図鑑・エリア解放
- 有料ガチャにしない理由

## 課金の設計

- Pro 月680円（本体アプリもProになる）
- Free 1日2回（はじめの7日間は3回）／Pro 1日10回の理由
- 無料の回数は減らさず、足すだけ

## 広告

- AdSenseでタイマー広告がNGな理由
- 「区切り＋5分」の実装
