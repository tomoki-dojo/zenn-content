英語を声に出して練習すると、クワガタが育つ。そんな英語学習ゲーム「**喋って！育てろ！英クワたん**」を Claude を使いながら 1 人で作ってリリースしました。

https://app.upskillenglish.bear-fruit.online/welcome?utm_source=zenn&utm_medium=article&utm_campaign=kuwatan-solo-dev-overview

もともと教員をやっていたので純粋なプログラマーというわけではないですが、そもそも独学で Gatsby 製のブログなんか作ってました。

が、ここ 1，2 年は AI がスゴいですね、もはや AI 無しでの開発なんか考えられません。AI バンザイ笑

ということで、この記事では、作ったものの全体像を、

- どういう仕組みで「話す練習」をさせているか
- AI の判定に実際いくらかかっているか
- 課金と広告をどう設計したか

の 3 つを中心に、実際の数字つきでまとめます。細かい実装は、別の記事で 1 つずつ書いていく予定です。

## なぜ作ったか

英語学習アプリはたくさんありますが、多くは「読めた」「正しい選択肢を選べた」で終わります。でも、話せるようになりたい人に必要なのは、**口から英語を出す練習**です。

そこでこのアプリでは、全部のステップで「実際に声に出す」ことを目標にしました。もちろん発声ができたかどうか？の判断をユーザーに任せる部分もありますが…。

もう 1 つの問題は、こういった練習ができるコンテンツが少ない、ということです。

声に出す練習をした方がいいのはわかるけど、英文を読んだりしても「なんか…これで会話ができるんかな？」と思いがちです。

要は上手く練習するシチュエーションみたいなのがなかなか無いんですよね。

なので、「ないなら作ってしまえ！」と **「英会話ができるシチュエーション設定」** をアプリで作ったんですが…正直面白くないというか、勉強だけだったらなかなかモチベーションがあがらない。

そこで、**練習するほど何か育つような育成ゲームと組み合わせれば楽しく続けられるのでは？**ということで、ゲームを組み合わせました。

## 全体の構成

| 役割          | 使っているもの                                      |
| ------------- | --------------------------------------------------- |
| フロント・API | Next.js 15（App Router）                            |
| DB・認証      | Supabase（Postgres、マジックリンクでログイン）      |
| 課金          | Stripe（Checkout ＋ カスタマーポータル ＋ Webhook） |
| AI 判定       | Gemini 3.5 Flash-Lite（予備に Claude Haiku 4.5）    |
| 音声入力      | ブラウザの Web Speech API                           |
| サーバー      | ConoHa VPS（Docker ＋ Caddy）                       |
| 計測・広告    | GA4、AdSense                                        |

最初は Vercel の無料プランで動かしていましたが、Stripe で課金を付けた時点で「商用利用」にあたると気づき、VPS に移しました。今は同じ VPS で、自動化ツールの n8n や別の自作アプリも一緒に動いています。

## 「話す練習」の仕組み：Stage0〜5

練習は、Stage1〜5 で構成されていて、だんだん難易度が上がっていきます（Stage0 は Stage を進める前の前提、という位置づけです）。

Stage4、5 ではシチュエーション別に実際に会話を想定して、AI と会話のやり取りをしていきます。

| Stage | 中身                                 | 判定                    |
| ----- | ------------------------------------ | ----------------------- |
| 1     | 音読・シャドーイング                 | 自己申告（AI なし）     |
| 2     | 瞬間英作文（声に出して組み立てる）   | 自己申告（AI なし）     |
| 3     | 型を崩して、自分の言葉で言い換える   | **AI が意味を判定**     |
| 4     | AI とロールプレイ（5 往復の会話）    | **AI が会話全体を判定** |
| 5     | 応用（日常・ビジネスの難しめの場面） | **AI が会話全体を判定** |

ポイントは、**AI を使うのは Stage3〜5 だけ**にしたことです。

Stage1、2 は「同じ表現を何度も口に出して覚える」量の練習なので、正誤を AI に判定させる必要がありません。というより、まずは表現をインプットしつつ、声に出してね、という感じですね。

答えを確認して「言えた／言えなかった」を自分で押してもらう形にしています。ここで AI を使わないことで、大分コストを抑えています。

同じ表現を連続で何回か言えたら「習得」で、習得した数で次の Stage が開きます。

## AI の判定にいくらかかっているか

Stage3 も AI を使うのですが、ここがいわゆる表現の正誤判定です。ただ、音声認識でそのまま判定をしてしまうと、音声認識の精度もあるのでちょっとユーザーにとってストレスになりかねません。

「こう言ったはずなのに…」というのがあり得るので、ブラウザの音声入力を使って表現を送信する（あとで修正もできる）「疑似会話」みたいな感じのシステムにしています。

Stage3 では１回分（その表現が習得になる最後の段階では会話のやり取りで２回分）の AI 呼び出しを行います。

Stage4、5 でも基本的な構造は同じです。ただ、実際の会話を想定して 5 往復やり取りをする構成にしています。

ということで、気になる API のコストは次のような感じになります。Stage4 を実際に 3 回やって、API の使用量を測りました。

|              | 1 回の会話あたり           |
| ------------ | -------------------------- |
| リクエスト数 | 15                         |
| 入力トークン | 約 16.9K                   |
| 出力トークン | 約 1.6K                    |
| 費用         | 約$0.009（**約 0.45 円**） |

Stage5 もほぼ同じで、約 0.4 円でした。

※単価は $0.30（入力）／$2.50（出力）per 1M トークン、1 ドル 150 円で計算しています。単価は公式の料金ページではなく第三者の情報で確認したものなので、目安として見てください。

### コストを抑えるためにやったこと

**1. 速くて安いモデルを主にして、落ちたときだけ別の AI に切り替える**

判定は Gemini 3.5 Flash-Lite を主にしています。実測で応答の中央値は約 1 秒でした。混雑やエラーのときは短いタイムアウトで見切りをつけて、Claude Haiku 4.5（中央値約 1.8 秒）に切り替えます。どちらかが落ちても、待ち時間が延びすぎないようにしています。

Gemini の API は速くて安いのがメリットですね。今回のように複雑な処理ではなく、会話を想定して「送られた文を理解する」→「それに対して返答する」くらいだったら十分な精度で返してくれます。

**2. お手本と完全に一致したら、AI を呼ばない**

Stage3 で、お手本とまったく同じ文を言えた場合は、AI に聞くまでもなく正解です。この場合は判定を省略しています。

このあたりの AI API のコストは自分のおサイフに直結するので、結構真剣に実装計画を考えました笑

## 続けたくなる仕組み：クワガタ育成

![](/images/kuwatan-solo-dev-overview/map.png)

練習とゲームは、次のようにつながっています。

メインは「クワたんシリーズ」の育成ですが、その他にも５０種類を超える虫を採集しに出かけることができます。

- 表現を**10 個習得するごとに「採集チャンス」が 1 回**たまる
- チャンスを使って、エリアを選んで採集に出かける
- 出かける前に「10 秒単語チャレンジ」があり、正解数が多いほどレアが出やすくなる
- 捕まえた虫は棚の水槽で歩き回り、習得した表現が増える毎に大きくなっていく
- Stage の節目では、主役のクワガタ「クワたんシリーズ」が卵で届く
- 「クワたんシリーズ」は日数と練習で卵 → 幼虫 → 蛹 → 成虫と育つ

「英語を聞かせると育つ不思議なクワガタ」という設定にしているので、練習した量と育つことがつながるようにしています。

## 課金の設計

課金は **Pro（月 680 円・年 6,800 円）の 1 本**だけです（2026 年 12 月 31 日までは先行者価格で月 480 円。後述）。英クワたんとは別に、表現や単語を調べられる本体アプリ（UpskillEnglish）もあり、Pro にすると両方が Pro になります。

|                        | Free                                | Pro        |
| ---------------------- | ----------------------------------- | ---------- |
| AI 判定（Stage3）      | 1 日 8 回                           | 1 日 50 回 |
| AI 会話（Stage4・5）   | 1 日 2 回（はじめの 7 日間は 3 回） | 1 日 10 回 |
| 棚に飾れる虫の種類     | 10 種類まで                         | 無制限     |
| 採集チャンスのたまり方 | ふつう                              | 2 倍       |
| Pro 限定のエリア・虫   | なし                                | あり       |
| 広告                   | あり                                | なし       |

棚に飾れる虫の種類無制限はゲーム的に結構デカいですね。もちろん Free でも捕まえた虫のデータは保存しているので、採集エリア解放とかは問題なくできます（エリアの解放判定に採集した虫の種類の数を使ってる）。

### カード登録なしで 7 日間試せる、先行者は月 480 円

せっかくなので沢山の人に遊んでもらいたい！そしてできれば課金していただきたい！笑

ということで、リリースに合わせてサービスを 2 つ用意しました。

- **7 日間の無料お試し（カード登録なし）**：お試しが終わると、自動で Free に戻ります。カードを登録しない限り、お金はかかりません
- **先行者価格**：2026 年 12 月 31 日までに Pro を始めた人は、**月 480 円**（月払いのみ）。そのあとも 480 円のまま続けられます

「無料お試し」は、カードを先に登録させる形が多いと思います。そのほうが課金に切り替わる人は増えますが、「解約し忘れて払っていた」は…まぁ正直印象が悪いので、カード登録なしでもお試しができるようにしています。

Stripe Checkout だと、設定 3 つで作れます。

```ts
const session = await stripe.checkout.sessions.create({
  mode: "subscription",
  line_items: [{ price: priceId, quantity: 1 }],
  // カードがなくても申し込めるようにする
  payment_method_collection: "if_required",
  subscription_data: {
    trial_period_days: 7,
    trial_settings: {
      // お試し終了時にカードがなければ、請求せずに解約
      end_behavior: { missing_payment_method: "cancel" },
    },
  },
  // 申し込みボタンの下に注意書きを出す
  custom_text: {
    submit: {
      message:
        "7日間のお試しが終わると、自動的にFreeプランに戻ります。カードを登録しない限り、お支払いが発生することはありません。",
    },
  },
  // ...success_url など
});
```

お試しは 1 人 1 回です。過去にサブスクリプションを持ったことがあるかを Stripe に問い合わせて、2 回目以降は通常の申し込みにしています。

その代わり、お試し中は部屋の上に「あと ◯ 日」を出し、最終日の前日と当日は「明日で／今日でお試しが終わります。カードを登録すると月 480 円のまま続けられます」に切り替えています。黙って終わるより、続けたい人がちゃんと気づける形にしました。

### 回数はコストより「体験」で決めた

0.45 円の会話を 1 日 10 回使い切っても、1 日 4.5 円、Stage4・5 の両方で月 270 円ほどです。月 680 円に対して赤字にはなりません。

Free の回数は、コストより「習得のしやすさ」で決めました。Stage4 は同じ場面で 3 回続けて合格すると習得なので、1 日 2 回だと初日に 1 つも習得できません。そこで、**はじめての 7 日間だけ 1 日 3 回**にしています。登録した日からではなく、その Stage を初めて遊んだ日から数えるので、Stage4 にたどり着いた人は必ずこの 7 日間を使えます。

ここらへんはユーザー体験を第一に考えて結構丁寧に設計しました。

### 一番課金したくなるのは「棚がいっぱい」のとき

遊んでいて一番「Pro にしようかな」と思う瞬間は、AI の回数よりも、**棚に飾れる種類が 10 種類で埋まったとき**だと考えています。もう捕まえた子が、棚に飾れないからです。

なので、11 種類目を捕まえた結果画面で「棚がいっぱいで、この子は飾れない…」と出して、Pro の案内につなげています。棚には、隠れている種類の数だけ鍵付きの水槽を並べています。

## 広告：タイマーでは出さない

Free の人には AdSense の広告を出しています。ただ、**一定時間ごとに勝手に出す、ということはしていません**。

AdSense は、ユーザーの操作なしに広告を出したり再読み込みしたりするのを認めていません。それに、声に出して練習している最中に広告が割り込んだら、一番やめたくなる瞬間になります。

そこで、

- 練習から部屋・棚・図鑑に戻ったとき
- 採集の結果を閉じたとき

という**区切りのいい場面で、前回の広告から 5 分以上たっていたら**、ページの上に広告を 1 つ出すだけにしています。

- AI の回数の上限に当たった
